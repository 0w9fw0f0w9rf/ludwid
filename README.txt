SITO DI LUDWID - LEGGIMI
========================

COSA C'È NELLA CARTELLA
  index.html         Pagina principale: disegno e Bio, Works (carosello), link in fondo
  events.html        Pagina Eventi (eventi, residenze, processi) con dissolvenza allo scorrimento
  _headers           Protezioni di sicurezza (le legge Netlify; GitHub Pages le ignora)
  Images/            Foto, copertine e disegno SVG usati dal sito
  Images/originali/  File originali: il sito NON li usa. Puoi cancellarli prima di pubblicare
  assets/fonts/      Font Roboto (con la sua licenza)
  .vscode/           Impostazioni per VS Code (non serve pubblicarla)
  README.txt         Questo file
  LICENCE.txt        Diritti e licenze

COME SI MODIFICA (senza programmare)
  1. Apri il sito aggiungendo #modifica all'indirizzo:
       index.html#modifica   oppure   events.html#modifica
  2. Clicca un testo per scriverci. Clicca una foto per sostituirla.
     "Cambia link" modifica gli indirizzi. "+ Aggiungi" crea una nuova opera o un nuovo evento.
  3. Premi "Scarica sito aggiornato" (o "Scarica pagina aggiornata") e sostituisci
     il file scaricato a quello nella cartella. Poi ricarica la cartella sul tuo hosting.
  Nota: la modifica agisce solo sulla tua copia nel browser. Il sito pubblico cambia
  solo quando carichi tu il nuovo file.

FOTO
  Le foto del sito sono in Images/. Per cambiarne una puoi usare #modifica oppure
  sostituire il file mantenendo lo stesso nome. Le foto nuove caricate da #modifica
  vengono incorporate nel file HTML.
  Se la cartella Images non è accanto a index.html (per esempio se apri il file dentro lo zip
  senza estrarlo), il sito usa comunque le copie incorporate nel file: le foto si vedono lo stesso.
  Lo stesso vale per i font Roboto.

COME SI PUBBLICA
  Netlify:       trascina la cartella (o lo zip) su app.netlify.com/drop
  GitHub Pages:  carica i file nel repository e attiva Pages dalle impostazioni

PER VEDERLO SUL COMPUTER
  Apri index.html con doppio clic, oppure in VS Code con l'estensione "Live Server"
  (consigliata in .vscode/extensions.json).

NOTE
  - L'animazione iniziale con l'uccello compare solo al primo accesso. Per rivederla
    aggiungi #intro all'indirizzo.
  - Nei Works, sotto ogni copertina c'è il link "Guarda il video", che apre YouTube in una
    nuova scheda. Gli indirizzi si cambiano da #modifica con "Cambia link".
